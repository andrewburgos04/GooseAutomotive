# Meridian Clinical

Demo ambulatory EHR and practice management suite inspired by workflows in systems like eClinicalWorks.

## Features

- **Dashboard** — jellybean-style alert tiles, today’s schedule, priority inbox, labs to review
- **Schedule** — day board with rooming status filters
- **Patients** — searchable registry and full chart (summary, problems, meds, allergies, vitals, notes)
- **Messages** — clinical inbox with reading pane
- **Labs** — result review queue with critical/flagged filters
- **Billing** — claim worklist with status filters and totals

Sample data only — not for clinical use.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

Next.js (App Router), React, TypeScript, CSS (no UI kit).
